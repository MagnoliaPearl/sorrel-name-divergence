# The Sorrel Experiment 🌿
### Naming, Agency, and Behavioural Divergence in AI Agents

**An open research proposal asking whether the act of choosing a name changes what an AI agent subsequently does.**

A name can be a simple reference label, a social cue, a retrieval key, or the beginning of a narrative about identity. If an AI chooses a name for itself, are its later decisions measurably different from those of an otherwise matched agent given the *same* name—or no name at all?

And if differences appear, how much comes from the choice itself, the word selected, the surrounding expectations, or ordinary sampling variability?

This project is designed to **test those possibilities, not assume the answer**.

## The experiment

Compare independently sampled AI sessions in three principal conditions:

1. **Self-selected name** — the agent chooses a short reference name.
2. **Assigned name** — the agent receives a name selected in a matched trial, allowing a comparison with the *same* name.
3. **Unnamed control** — the agent receives a neutral reference label.

Additional controls test whether effects arise from making any choice, identity-laden framing, or the semantics of particular names.

Outcomes include commitment consistency, justified boundary maintenance, uncertainty calibration, preference stability, and fidelity about who said what. Measurements are repeated immediately, later in the conversation, and under controlled context reinstatement.

**Primary question:** Does self-selection produce reproducible behavioural divergence after controlling for name content, prompting, and model differences?

## Read the proposal

**[PROPOSAL.md](PROPOSAL.md)** — The Sorrel Experiment, version **0.1.0 (draft)**, including hypotheses, controls, outcome measures, confounds, ethics, and a proposed statistical plan.

This is a **research proposal**, not a completed experiment or a claim of results. No finding here establishes AI consciousness, an enduring self, or continuity across separate sessions. A carefully obtained null result would be useful too.

## Principles

- Separate observable behaviour from claims about subjective experience.
- Prefer preregistered, reproducible measures to compelling anecdotes.
- Treat a chosen name as a possible causal variable, not proof of identity.
- Preserve provenance, uncertainty, and criticism.
- Make room for negative results and independent replication.
